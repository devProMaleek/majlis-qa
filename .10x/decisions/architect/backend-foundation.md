# Backend foundation

See ADR 002. Implement three milestones: (1) versioned schema and least-privilege grants/RLS, verified against local Supabase/PostgreSQL; (2) typed clients, cookie refresh, validated email/password sign-in and protected read-only staff workspace; (3) database, Auth and browser tests plus environment/runbook documentation. No submissions, invitation UI, full event CRUD UI or moderator mutations.

The existing uncommitted foundation remains intact and no commit/push/PR is authorised. The user's request to continue implementation supersedes the previous implementation pause, not the commit gate.
